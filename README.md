# WhatsApp 360° Vision

Central de monitoramento do atendimento no WhatsApp da rede Apaixonados Por Quatro Patas.
Software desenvolvido pela Daco Vet em parceria com Apaixonados Por Quatro Patas.

Site estático (HTML, CSS e JS puro). Os dados vêm de uma API própria; nenhum dado
de cliente fica neste repositório. Acesso só com login.

- `index.html` — casca
- `app/` — tema, camada de dados e as telas
- `banco/` — funções SQL que a API usa (referência)
